## Full Description
LearnExcel is a premium, mobile-first interactive learning platform designed to teach Microsoft Excel functions through hands-on practice. Unlike traditional video-based courses, LearnExcel features a custom-built spreadsheet engine that allows users to type and test formulas directly on their mobile devices.

### Key Features:
- **Mobile-Only Experience**: Fully optimized for mobile screens with a dedicated desktop callback page.
- **Interactive Spreadsheet Engine (SheetLab)**: A powerful sandbox to practice 100+ Excel functions with real-time evaluation.
- **Gamified Learning Path**: Earn XP, maintain streaks, and unlock trophies as you progress through curated lessons.
- **Comprehensive Curriculum**: Over 10 categories including Foundations, Logical, Math, Statistical, Lookup, Financial, and more.
- **Progress Syncing**: Seamlessly save your progress across devices using Supabase and Firebase.
- **Modern UI/UX**: Dark mode first, glassmorphic design, and smooth Framer Motion animations.
- **Performance Optimized**: Built with Next.js 15 for lightning-fast load times and low data usage.

### Tech Stack:
- **Frontend**: Next.js 15 (App Router), Tailwind CSS 4, Framer Motion
- **Authentication**: Firebase Auth (Google Login)
- **Database**: Supabase
- **Cache/Rate Limiting**: Redis (Upstash)
- **State Management**: Zustand
- **Formula Parsing**: Custom engine + hot-formula-parser
